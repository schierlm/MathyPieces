# MathyPieces
Collection of math-related niche tools, based on [CRCalc.js Exact Calculator](https://crcalc.js.org/calc.html)

## Website

https://schierlm.github.io/MathyPieces/

## Compiling

You don't need any npm or bundler, just run `tsc` (or `tsc --watch` when testing), and serve the repo
via a local webserver. Everything that is not (ES2022) TypeScript modules is vanilla (inline) JavaScript.
